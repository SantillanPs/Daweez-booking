02

The fix is one line

WalkInBookingForm.tsx:389

const openAgencyProfile = (deal: PartnerDeal | null, draftName: string) => {
  setAgencyProfile({ deal: deal ?? (formPartnerDealId ? partnerDeals.find(d => d.id === formPartnerDealId) ?? null : null), draftName })
  setAgencyProfile({ deal, draftName })
}

Nothing else changes: ＋ New agency then opens a genuinely blank profile headed New agency, and saving adds a new agency with its own new id instead of touching the selected one.

what the notes claim

i.e. Change would open Edit agency for the agency already on the booking.

what the code does

Change reopens the agency picker — the search box and the saved list — so you can name a different agency.

No profile is opened, so nothing can be overwritten by accident.

I have not changed either behaviour — the one-line fix above is the whole build. I only need to know which of the two is what you actually want, so the code and the notes stop disagreeing.
