- **An agency booking IS a normal booking — it only ADDS to the form** (the owner's ruling, 2026-09, from his own note: *“the agency feature is supposed to be a custom set pricing, not automatic booking … it should just change the pricing of the rooms specifically for them”*, and from the hotel's real PGO bill, which is addressed to the office with the guest as `c/o`).   - **`BookingDepositFields` grew a second row, `Paid by`** — the same four methods as the till, read from `PAYMENT_METHODS` so the form and the quick view can never offer different choices. **Nothing is preselected**; `''` is a real state and a quiet line asks for a choice.

A failed write throws and the submit's own rollback cancels every booking just created, so the form can never finish on a booking whose payment did not land.
